# 🐦 Twitter Clone

A responsive Twitter/X clone UI built with HTML and Tailwind CSS. This project recreates the core visual layout of X, including the sidebar navigation, post composer, feed, post actions, search bar, trending section, and "Who to Follow" sidebar.

## ✨ Features

* 🏠 Home / For You feed layout
* 🔎 Search bar
* 🔔 Notifications navigation
* 🤖 Grok navigation item
* 📋 Lists and Bookmarks
* 👥 Communities
* 💎 Premium section
* 👤 Profile and More navigation
* ✍️ Post composer UI
* 🖼️ Image post with engagement actions
* 📈 Trending topics section
* 👥 Who to Follow section
* 🌙 Dark theme inspired by X/Twitter
* 📱 Responsive layout using Tailwind CSS
* 🚫 Hidden scrollbars for a cleaner interface

## 🛠️ Technologies Used

* HTML5
* Tailwind CSS
* SVG Icons
* Google Material Symbols
* Google Fonts


## 🎨 UI Sections

### Left Sidebar

Contains navigation items such as:

* Home
* Explore
* Notifications
* Grok
* Lists
* Bookmarks
* Communities
* Premium
* Profile
* More
* Post button

### Main Feed

The main feed contains:

* For You / Following tabs
* Post composer
* Image post
* Post engagement actions
* Comments, reposts, likes, views, and share icons

### Right Sidebar

Contains:

* Search
* What's Happening / Trending
* Who to Follow
